# Riakawa 0.1.0 status

The mod and music pack are uploaded with public visibility. Steam subscription
installation passes. The music pack's anonymous page opens; the mod page still
returns an access error.
See the [release report](RELEASE-REPORT.md) for package hashes and publication status.

## Completed

- Three characters and 1,278 weapon appearances for 426 vanilla weapons.
- Held weapons, projectiles, chains, whips, beams, minions and scoped effects.
- Korean/English settings, V emotes, hurt/death voices and multiplayer synchronization.
- Twelve music themes mapped to 89 vanilla/Otherworld tracks. The user approved the
  final tracks and loop boundaries on 2026-10-07.
- Native combat replays for all 426 weapons with each character. All compared combat
  fields match across 460,080 ticks; four display/audio fields are explicitly excluded.
- A new profile loads only the Workshop mod and music pack, with no local packages
  or QA helper mod. Default emotes, Korean settings and captured music playback pass.
- Public descriptions, configuration text and documentation have been edited for
  plain Korean and English. Character dialogue and license text remain unchanged.

The [appearance review](APPEARANCE-REVIEW.md), [QA guide](QA.md) and
[credits](CREDITS.md) describe the tested scope, checks and asset sources.
Earlier development records remain in Git history and local `artifacts/` files.
GPU instances used for asset generation have been destroyed.
