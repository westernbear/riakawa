# Riakawa 0.2.0 status

Momonga is the fourth playable character. The mod now has 1,704 weapon appearances
for 426 vanilla weapons, twelve voice cues and 52 weapon/instrument sounds.
The twelve-theme music pack is unchanged from 0.1.0.

Momonga's asset, pose, runtime loading, voice and two-client checks pass. All
426 weapons match the native baseline across 153,360 simulation ticks.
The 0.2.0 Workshop download matches the release package and loads in a new profile
with no QA helper. Steam reports public visibility; the mod's anonymous page still
returns an access error. The music pack's page opens.
See the [release report](RELEASE-REPORT.md) for build hashes and results.

The original three characters' 0.1.0 combat and Workshop installation records are
preserved separately. Public descriptions and settings use plain Korean and English;
character dialogue and license text are preserved. All GPU instances used for
Momonga's voice generation have been destroyed.
