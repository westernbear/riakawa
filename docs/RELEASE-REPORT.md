# Riakawa 0.2.0 출시 검수

모몽가를 네 번째 캐릭터로 추가했다. 36개 동작 프레임, 무기 426종의 외형과
공격 자산, 감정표현·피격·사망 음성을 제공한다. 사용자는 현재 도트로 진행하도록
승인했다. 지원 환경은 PC Steam Terraria 1.4.4.9와 tModLoader v2026.08.3.0이다.

감정표현, 원래 모습 복원, 분열 발사체의 무기 정보와 재접속 후 기존 소환수를 확인했다.
효과 감소·장식 끄기·무기 교체 끄기도 검사했다. 전용 서버는 클라이언트 자산을 로드하지 않는다.

피격·사망 음성은 듣는 사람의 설정을 따른다. 원래 모습은 기본 소리를 사용하며,
원본의 무음 피해는 그대로 유지한다. 녹음 비교는 파일과 실제 출력의 일치 검사다.
모몽가 음성의 최종 청음 승인은 별도로 받지 않았다.

자세·대표 공격 검사는 음성 연결과 보조 이미지 알파 수정 전의 렌더링 빌드에서
실행했다. 파일·알파 검사와 최종 패키지 로드·음성·멀티플레이 검사는 수정 후 결과다.
각 실행의 해시와 범위는 [검수 기록](qa/momonga-review.json)에 남겼다.

## 기존 검사와 범위

초기 세 캐릭터는 0.1.0에서 무기 426종씩 총 460,080틱의 전투 비교를 통과했다.
[이전 전투 기록](qa/live-combat-summary.json)과 [외형·공격 검수](APPEARANCE-REVIEW.md)는
당시 빌드를 기준으로 보존한다. 기존 세 캐릭터의 플레이어 이미지와 파티클 셀은 바뀌지 않았다.

전투 시험은 맑은 낮의 돌바닥·벽이 있는 시험장에서 슬라임·좀비·박쥐의 실제 AI를
실행한다. 무기마다 360틱을 기록하고 피해·넉백·공격 간격·소모량·히트박스·좌표·
속도·충돌·투사체 수명을 비교한다. 체력·마나·탄약을 보충하지 않는다. 난수 시드와
지형 버프 갱신 시점을 맞추고 256틱 묶음 사이에 화면을 그린다.

원본 AI 배열의 색상 값 1개와 소리 핸들 3개는 [정확한 필드 목록](qa/combat-cosmetic-fields.json)에
따라 비교에서 제외한다. 나머지 AI 값과 전투 상태는 모두 비교한다.
모든 지형·장비·난수·다른 모드 조합을 시험한 것은 아니다. 소프트웨어 렌더러를 사용했으므로
일반 PC의 성능 측정은 포함하지 않는다. 원본 캡처·녹음·로그는 로컬 `artifacts/qa/`에 보존한다.
