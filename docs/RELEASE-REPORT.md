# Riakawa 0.1.0 출시 검수

지원 환경은 PC Steam Terraria 1.4.4.9와 tModLoader v2026.08.3.0이다.
세 캐릭터의 전투 비교와 구독 설치 검수를 통과했다. 모드와 음악 팩은 Steam API에서
공개 상태다. 음악 팩의 비로그인 페이지는 열리며, 모드 페이지의 접근 여부는 확인 중이다.
최종 음악은 사용자가 2026-10-07에 전곡과 루프 연결부를 듣고 공개를 승인했다.

기존 게임 검수에서는 두 클라이언트의 캐릭터·감정표현·소환수 동기화와 설정 변경,
재접속을 확인했다. 피격·사망 음성은 15개 사례를 비교했고 실제 출력 6개가 배포 음성과
일치했다. 기본 피해량·넉백·무음 플래그를 유지하면서 듣는 사람의 음성 설정을 따른다.

음악은 낮·밤·이벤트·보스·최종 보스·Otherworld·음악상자·볼륨 0을 포함한 10개
실행 사례에서 선곡과 페이드를 확인했다. 녹음으로 식별한 트랙은 9개다. 이 기록은
이전 검수 빌드에서 얻었으며, 최종 청음 승인은 별도 사용자 검토에 근거한다.

## 검사의 범위

외형 검사는 20,448개 원본 무기 자세, 기본 공격 426종, 탄약 114개 대표 조합과
단독 소환 38종을 포함한다. 일부 외형 시험에서는 표적을 고정하고 마나를 보충했다.
전투 성능 비교는 Riakawa 없는 별도 게임 실행을 기준으로 했다.

전투 시험은 맑은 낮의 돌바닥·벽이 있는 시험장에서 슬라임·좀비·박쥐의 실제 AI를
실행했다. 무기마다 360틱을 기록하고 피해·넉백·공격 간격·소모량·히트박스·좌표·
속도·충돌·투사체 수명을 비교했다. 체력·마나·탄약을 보충하지 않았다. 난수 시드와
지형 버프 갱신 시점을 맞췄으며, 화면 그리기는 256틱 묶음 사이에 실행했다.

원본 게임이 AI 배열에 보관하는 색상 값 1개와 소리 재생 핸들 3개는 비교에서 제외했다.
[원본 코드 검토 기록](qa/combat-cosmetic-fields.json)에 정확한 필드를 남겼다.
그 밖의 AI 값과 모든 전투 상태는 그대로 비교했고 원본 기록은 수정하지 않았다.
이 시험은 정해진 입력과 시험장 조건에서의 비교다.

원본 캡처·녹음·실행 로그는 로컬 `artifacts/qa/`에 보존한다. 공개 저장소에는
검사 요약과 실제 플레이 스크린샷을 싣는다. 모든 장비·지형·난수·다른 모드 조합을
시험한 것은 아니다. 소프트웨어 렌더러로 검수했으므로 일반 PC의 성능 측정은 포함하지 않는다.

자산 생성에 사용한 GPU 인스턴스는 모두 삭제했다. 비상업 팬 프로젝트의 소재·모델·
글꼴 출처는 [크레딧](CREDITS.md)에 정리했다.
